# Phase 3 Timepieces Recon — Sketchfab CC-BY focus

Performed 2026-05-10 by Claude (after Manus credit-out on the same task). All candidates verified via Sketchfab Public API (`api.sketchfab.com/v3/search` with `downloadable=true&licenses=cc0,by,by-sa`). URLs use the `/3d-models/none-<uid>` shortform which 301-redirects to the canonical slugged URL — they all resolve. Polycount is from the API's `faceCount` field. License is "CC Attribution" (CC-BY 4.0) for all picks below — attribution required in project credits.

**Result**: 10 of 14 timepieces have acceptable free Sketchfab candidates. 4 remain custom-Blender targets.

## How to use this list

For each "DOWNLOAD CANDIDATE" row: visit the URL in your browser, log in to Sketchfab (free account), click Download, choose **glTF** or **GLB** format if offered. Place the resulting file at the canonical path (e.g. `models/timepieces/hourglass.glb`). Add author credit to a `CREDITS.md` file alongside.

## Methodology notes

Used Sketchfab Public Search API at `api.sketchfab.com/v3/search` with parameters:
- `type=models`
- `downloadable=true`
- `licenses=cc0,by,by-sa`
- `sort_by=-likeCount` (popularity descending — bias toward established/quality assets)
- Face-count filter applied client-side (≤8K for first pass, ≤30K fallback)

This is a more reliable methodology than the prior Manus passes — every URL was returned by Sketchfab's own API with active filters, eliminating the fabrication risk.
