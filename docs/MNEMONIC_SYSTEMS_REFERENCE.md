> Source: Perplexity research on metacognitive & learning frameworks.
> Filed here because MindHause IS a Method of Loci implementation — these systems
> are directly relevant to the app's core concept and future feature design.

## The Five Systems

### 1. Method of Loci (Memory Palace)
The spatial framework — and MindHause's entire premise.

- Pick a familiar building/route with fixed locations (loci)
- Place vivid mental images at each location to encode information
- Walk the route mentally to recall in sequence
- Leverages hippocampal spatial memory — the brain's strongest recall system
- Scales: 10-room palace = 10+ items; 100-location journey = 100+ items

**Choosing effective palaces:**
- Highly familiar, emotionally neutral/positive spaces
- Clear linear path without backtracking
- Distinct landmarks at each locus (not repetitive)
- One topic per palace for long-term use
- Right size for the job (single room for short lists, building for domains)

### 2. Major System (Phonetic Number System)
Converts digits 0-9 into consonant sounds, making numbers into words/images.

| Digit | Sounds |
|-------|--------|
| 0 | s, z, soft c |
| 1 | t, d, th |
| 2 | n |
| 3 | m |
| 4 | r |
| 5 | l |
| 6 | j, sh, ch, soft g |
| 7 | k, hard c, hard g, q |
| 8 | f, v |
| 9 | p, b |

Example: 314 → m-t-r → "motor" or "meteor" → vivid image placed in palace.

### 3. Dominic System (00-99)
Each 2-digit pair maps to a person + characteristic action via initials.

| Digit | Letter |
|-------|--------|
| 1=A, 2=B, 3=C, 4=D, 5=E, 6=F, 7=G, 8=H, 9=I, 0=O |

Example: 36 → C.F. → Charlie Chaplin → walking with a cane.

For sequences: chain person-actions into stories placed in palace rooms.

### 4. PAO System (Person-Action-Object)
Extends Dominic to 3 components per 2-digit number.

Each 00-99 pair gets:
- **Person** (e.g., 21 = Michael Jordan)
- **Action** (e.g., 21 = dunking)
- **Object** (e.g., 21 = basketball)

6-digit numbers become single vivid scenes. This is how memory champions
memorize card decks and long random numbers.

### 5. 12 Mnemonic Categories (Mental Filing Cabinet)
Higher-level organizational system — groups all knowledge into 12 domains:

1. **People** — names, faces, biographies
2. **Places** — geography, routes, buildings
3. **Numbers** — dates, stats, formulas
4. **Words** — vocabulary, foreign words
5. **Concepts** — ideas, theories, principles
6. **Events** — history, timelines, stories
7. **Objects** — tools, artifacts, items
8. **Actions** — processes, procedures, skills
9. **Emotions/States** — feelings, moods, motivations
10. **Senses** — sounds, smells, textures
11. **Time** — past, present, future, durations
12. **Space** — positions, directions, layouts

Each category can have its own mini-palace or loci set.

## How They Layer Together

```
┌─────────────────────────────────────────────┐
│  12 MNEMONIC CATEGORIES                     │  ← File system (where to store)
│  (People, Places, Numbers, Concepts, etc.)  │
├─────────────────────────────────────────────┤
│  MAJOR / DOMINIC / PAO SYSTEMS              │  ← Encoding engines (how to encode)
│  (Turn abstract data into vivid images)     │
├─────────────────────────────────────────────┤
│  METHOD OF LOCI (MEMORY PALACE)             │  ← Spatial hard drive (the container)
│  (Rooms, routes, fixed loci)                │
└─────────────────────────────────────────────┘
```

## Medical Study Plan Example (Domain-Specific Palaces)

This example shows how a medical student would use one palace per subject:

| Subject | Palace | Main Mnemonics |
|---------|--------|---------------|
| Anatomy | "Anatomy Hospital" | Loci, imagery, acronyms |
| Physiology | "Phys Lab" | Story/chaining, schemas, loci |
| Pathology | "Path Museum" | Schemas, imagery, stories, acronyms |
| Pharmacology | "Pharmacy" | Peg/number, imagery, acronyms |
| Microbiology | "ID Ward" | Categories, loci, acronyms, imagery |
| Immunology | "Immune Command Center" | Stories, imagery, acronyms |
| Clinical Medicine | "Systems Wards" | Schemas, acronyms, stories, loci |
| OSCE Skills | "OSCE Clinic" | Step/procedural, acronyms, loci |
| Emergency/ICU | "Resus Bay" | Step/procedural, acronyms, pegs |

Key pattern: each domain gets a **dedicated palace** with rooms mapped to
sub-topics, and 2-3 primary mnemonic types are used consistently within it.
