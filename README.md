# MindHause

> Cross-platform mobile app built with Flutter

## Overview

MindHause is a cross-platform mobile application targeting **Android**, **iOS**, and **Web**. Originally conceived as a Godot project, it has been migrated to Flutter for rapid AI-assisted development.

## Tech Stack

- **Framework:** Flutter 3.38.x / Dart 3.10.x
- **Platforms:** Android, iOS, Web
- **Dev Environment:** WSL2 (Ubuntu)

## Getting Started

```bash
# Install dependencies
flutter pub get

# Run on connected device or emulator
flutter run

# Run on web
flutter run -d chrome

# Run tests
flutter test
```
